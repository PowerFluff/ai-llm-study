# Python-zero

## 0 - start
Just saying hello in terminal. Set up git, .gitignore, venv

venv is an virtual environment, used to install some libs (with compile process, where it need)

## Setting up:
- 1. git clone https://github.com/PowerFluff/ai-llm-study.git
- 2. python -m venv venv
- 3. venv\Scripts\activate 
- 4. pip install -r requirements.txt
- 5. python hello.py
